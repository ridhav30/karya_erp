### Karya Erp

Karya Erp

Generated by the Operator from `master_erp`. The UI is served at `/karya_erp`.

#### Features

- **Dashboard**: Dashboard
- **My HR**: My HR
- **Selling**: Point of Sale, Customers, Sales Invoices
- **Buying**: Suppliers, Purchase Orders, Purchase Receipts, Purchase Invoices
- **Stock**: Items, Warehouses, Stock Entries, Stock Balance, Stock Reconciliation, Batches
- **Pricing**: Item Prices, Price Lists, Pricing Rules
- **Accounts**: Overview, Accounts Receivable, Receive Payment, Receipt History, Accounts Payable, Make Payment, Payment History, Payments, Credit Notes, Financial Reports, VAT Return
- **Accounts Setup**: POS Counters, Shift Closings
- **Import data**: Import data
- **Audit log**: Audit log
- **Users & Access**: Users & Access
- **Custom**: Employee programs

#### Install

```bash
# put karya_erp.zip in the bench's apps/ folder, then from the bench folder:
cd $PATH_TO_YOUR_BENCH
[ -f apps/karya_erp/operator.json ] && rm -rf apps/karya_erp   # older version, if any
unzip -q -o apps/karya_erp.zip -d apps/
bash apps/karya_erp/install.sh [your-site]
# or run the steps below by hand, from the bench folder:
./env/bin/pip install -e apps/karya_erp
[ -z "$(tail -c1 sites/apps.txt)" ] || echo >> sites/apps.txt
grep -qx karya_erp sites/apps.txt || echo karya_erp >> sites/apps.txt
bench --site [your-site] install-app karya_erp   # already installed? use: bench --site [your-site] migrate

# Build the React UI (skip if the zip already has karya_erp/public/frontend)
cd apps/karya_erp/frontend && npm install && npm run build && cd -
bench build --app karya_erp
bench restart
```

The apps this one needs (ERPNext, and HRMS for HR features) are listed in `required_apps` and
`install.sh` installs them on the site if they are missing. They must be on the bench first
(`bench get-app erpnext`, `bench get-app hrms`), which is where you choose their versions.

> Install on a site that does **not** also have `master_erp`: both apps ship the same custom
> DocTypes (e.g. Employee Document, WPS Settings), and a DocType can belong to only one app.

#### Develop

```bash
cd apps/karya_erp/frontend
npm run dev        # http://localhost:5173, proxies API calls to bench on :8000
```

Menu entries live in `frontend/src/lib/nav.js` (`ENABLED` list at the bottom of `ALL_NAV`).
`operator.json` records what was taken from `master_erp`.
